# หน้าบริการและราคา

หน้า `/services` บอกผู้เยี่ยมชมว่าคลินิกมีบริการอะไร ราคาเท่าไร และใช้เวลานานแค่ไหน แล้วให้กดจองบริการที่ต้องการได้ทันที ไม่ต้องเข้าสู่ระบบ ปุ่ม **ดูบริการและราคา** ใน Hero ของหน้าแรก เมนู **บริการ** บน header ลิงก์ **บริการและราคา** ใน footer และลิงก์ใต้การ์ดบริการบนหน้าแรกพามาที่นี่

## ข้อมูลมาจากไหน

ทุกอย่างบนหน้าอ่านจาก API ทุกครั้งที่เปิดหน้า ราคาที่พนักงานแก้จึงขึ้นบนเว็บทันที

| ส่วน | API | หมายเหตุ |
|---|---|---|
| บริการ ระยะเวลา ราคา ราคาแยก และสาขาที่มีบริการ | `GET /services` | เฉพาะบริการที่เปิดใช้งานและเปิดจองออนไลน์ |
| ชื่อหมวดและลำดับหมวด | `GET /services/categories` | ถ้าอ่านไม่ได้ หัวข้อหมวดเป็นรหัสหมวดแทน |
| ชื่อสาขา | `GET /clinic/branches` | ใช้เมื่อคลินิกมีมากกว่าหนึ่งสาขา |

แก้บริการและราคาที่หน้าจอพนักงาน **ตั้งค่า > บริการและราคา** ดู [บริการ](services.md) บริการที่จองได้ที่เคาน์เตอร์อย่างเดียวจะไม่ขึ้นบนหน้านี้ ถ้าอยากให้ขึ้นต้องเปิดจองออนไลน์ให้บริการนั้น

## หน้าตา

1. แถบหัวสีเขียวเข้ม หัวข้อและคำอธิบายสั้น
2. ปุ่มหมวด กดแล้วเลื่อนลงไปที่หมวดนั้น ตัวเลขข้างชื่อคือจำนวนบริการ
3. หมวดละหนึ่งส่วน เรียงตามลำดับของ contract (ตรวจ วัคซีน ทันตกรรม ผ่าตัด แล็บ กรูมมิ่ง) แสดงเฉพาะหมวดที่มีบริการ บริการในหมวดเรียงตามที่ API ส่งมา
4. การ์ดบริการ ชื่อ ราคา ป้ายระยะเวลา ป้ายสาขา (ถ้าบริการไม่ได้มีทุกสาขา) ตารางราคาแยก (ถ้ามี) และปุ่ม **จองบริการนี้**
5. กล่อง **เรื่องราคา** บอกว่าราคาเป็นราคาตั้ง และหน้านี้มีเฉพาะบริการที่จองออนไลน์ได้
6. แถบสีส้มปิดหน้า ปุ่มจองนัดหมายและติดต่อคลินิก

ถ้า API ไม่ตอบ หน้ายังเปิดได้ และบอกว่ายังโหลดรายการไม่ได้พร้อมลิงก์ไปหน้าติดต่อ ถ้ายังไม่มีบริการที่เปิดจองออนไลน์เลย หน้าบอกให้โทรหรือนัดผ่านคลินิก

## ราคาแสดงอย่างไร

| กรณี | แสดง |
|---|---|
| ราคาเดียว | `฿500` |
| มีราคาแยกตามชนิดสัตว์หรือน้ำหนัก | `เริ่มต้น ฿400` คือราคาต่ำสุดในบรรดาราคาพื้นฐานและราคาแยกทุกแถว ใต้การ์ดมีตารางราคาแยกทีละแถว แล้วต่อด้วย **นอกเหนือจากนี้** ซึ่งคือราคาพื้นฐาน |
| ราคาเป็น 0 | `สอบถามราคา` |

ราคาเต็มบาทไม่มีทศนิยม ราคาที่มีสตางค์แสดงสองตำแหน่ง น้ำหนักสูงสุดของแต่ละแถวไม่นับรวม เหมือนที่หน้าจอพนักงานบอก เช่น `สุนัข 10 ถึงไม่ถึง 20 กก.`

ระยะเวลาเขียนเป็น `30 นาที` `1 ชม.` หรือ `1 ชม. 30 นาที`

## ปุ่มจองบริการนี้

ปุ่มไปที่ `/book?service=<id ของบริการ>` เช่น `/book?service=svc_checkup` หน้าจองจะเลือกบริการนั้นไว้ให้ ปุ่มในแถบสีส้มไปที่ `/book` โดยไม่เลือกบริการ ที่อยู่ของปุ่มตั้งที่ `serviceCard.bookHref` และ `servicesCta` ในไฟล์เนื้อหา

## แก้ข้อความ

ข้อความที่ไม่ได้มาจาก API อยู่ใน `frontend/src/features/service-catalog/content/services-page.ts`

| อยากแก้ | แก้ที่ |
|---|---|
| ชื่อแท็บและคำอธิบายสำหรับ Google | `servicesMeta` |
| หัวข้อและคำอธิบายบนแถบหัว | `servicesHero` |
| คำอธิบายใต้ชื่อหมวด | `categoryBlurbs` หมวดที่ไม่มีในนี้ไม่แสดงคำอธิบาย |
| ข้อความบนการ์ด (จองบริการนี้ เริ่มต้น สอบถามราคา) | `serviceCard` |
| กล่องเรื่องราคา | `servicesNote` |
| แถบสีส้มปิดหน้า | `servicesCta` |
| ข้อความตอนโหลดไม่ได้หรือยังไม่มีบริการ | `servicesPage` |

## ข้อจำกัด

- API ยังไม่มีคำอธิบายบริการหรือรายการว่าบริการรวมอะไรบ้าง การ์ดจึงมีแค่ชื่อ ราคา ระยะเวลา และสาขา ถ้าต้องการต้องเพิ่มช่องนี้ใน API ก่อน
- ไม่มีรูปบริการ เพราะ API ไม่มีที่เก็บรูปบริการ
- หน้า render ใหม่ทุกครั้งที่เปิด (`force-dynamic`) ไม่ทำ static เพราะตอน build อาจไม่มี API ให้เรียก
