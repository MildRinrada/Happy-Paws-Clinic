# หน้ากรณีฉุกเฉิน

หน้า `/emergency` บนเว็บสาธารณะ สำหรับเจ้าของที่น้องป่วยหนักหรือบาดเจ็บและต้องรู้เร็วที่สุดว่าต้องโทรเบอร์ไหน คลินิกเปิดอยู่ไหม อาการแบบไหนต้องรีบมา และระหว่างทางควรทำอะไร ไม่ต้องเข้าสู่ระบบ

> **ต้องให้สัตวแพทย์ของคลินิกตรวจก่อนเปิดใช้จริง** รายการอาการ สิ่งที่ควรทำ และสิ่งที่ไม่ควรทำ เป็นเนื้อหาทางการแพทย์ ตอนนี้เขียนตามคำแนะนำเบื้องต้นที่ใช้กันทั่วไป ยังไม่ได้ผ่านการตรวจของสัตวแพทย์คนใด สัตวแพทย์ของคลินิกต้องอ่านไฟล์ `frontend/src/features/emergency/content/emergency-care.ts` ทั้งไฟล์ แก้ให้ตรงกับที่คลินิกแนะนำจริง แล้วลงชื่อใน `clinicalReview` ก่อนเปิดหน้านี้ให้คนทั่วไปใช้ และต้องตรวจซ้ำทุกครั้งที่แก้ไฟล์

## ใครใช้

| ใคร | ทำอะไร |
|---|---|
| ผู้เยี่ยมชมเว็บ | เปิดหน้า `/emergency` ไม่ต้องเข้าสู่ระบบ ส่วนใหญ่เปิดจากมือถือ |
| สัตวแพทย์ของคลินิก | ตรวจและอนุมัติเนื้อหาทางการแพทย์ในไฟล์ข้อมูล |
| พนักงานที่ดูแลข้อมูลติดต่อ | ตั้งเบอร์ฉุกเฉิน เวลาทำการ วันหยุด และแผนที่ ในหน้าจอพนักงาน |
| คนดูแลเว็บ | แก้ข้อความของหน้าตามที่คลินิกบอก |

## หน้าตาและการทำงาน

1. **ส่วนหัวสีแดง** หัวข้อ คำแนะนำสั้น ๆ ว่าให้โทรก่อนออกจากบ้าน และปุ่มโทรขนาดใหญ่ ทั้งการ์ดคือปุ่ม แตะแล้วโทรออก (`tel:`)
2. **ตอนนี้คลินิกเปิดอยู่ไหม** การ์ดของแต่ละสาขา บอกว่าเปิดอยู่หรือปิดอยู่ ถ้าเปิดบอกเวลาปิดของวันนี้ ถ้าปิดบอกเวลาเปิดครั้งถัดไป เช่น "เปิดอีกครั้งพรุ่งนี้ 09:00" ถ้าวันนี้เป็นวันหยุดบอกชื่อวันหยุด ใต้การ์ดบอกเวลาที่ตรวจ และถ้ามีสาขาที่ปิดอยู่ บอกให้โทรถามก่อนว่าควรพาน้องไปที่ไหน ใต้ส่วนนี้มีกล่อง "เวลารอ walk-in ตอนนี้" บอกว่าตอนนี้น่าจะรอนานเท่าไร เช่น "ตอนนี้รอประมาณ 20 ถึง 30 นาที (3 คิว)" บรรทัดละสาขา พร้อมหมายเหตุว่าเคสฉุกเฉินได้ตรวจก่อนเสมอ อ่านจาก `GET /queue/wait-estimate` ใช้ร่วมกันทุกคน 30 วินาที ถ้าอ่านไม่ได้กล่องไม่ขึ้น ดู [คิว](queue.md#เวลารอ-walk-in-ส่วนขยาย)
3. **อาการแบบนี้ต้องพาไปหาหมอทันที** 11 อาการ แต่ละอาการมีคำอธิบายสั้น ๆ ว่าเห็นอะไร
4. **ระหว่างทางควรทำ** และ **สิ่งที่ไม่ควรทำ** สองการ์ดคู่กัน บนมือถือเรียงต่อกัน
5. **กล่องหมายเหตุ** บอกว่าเป็นคำแนะนำเบื้องต้น ไม่ใช่การวินิจฉัย และบอกว่าใครตรวจเนื้อหา
6. **เส้นทางมาคลินิก** แผนที่จากรายการแผนที่ของคลินิก ใช้ `MapPanel` ตัวเดียวกับหน้าติดต่อเรา ถ้าไม่มีรายการแผนที่ ส่วนนี้ไม่ขึ้น

ข้อความทั้งหมดเป็นข้อความธรรมดาในหน้า ค้นหาเจอได้และอ่านได้แม้ไม่เปิด JavaScript หน้านี้ไม่มีส่วนที่ต้องใช้ JavaScript เลย

## เบอร์ที่โทร

อ่านจาก `GET /clinic/contacts` รายการเดียวกับ footer และหน้าติดต่อเรา

- แสดงทุกรายการชนิด `emergency` เรียงรายการของทั้งคลินิกก่อน แล้วตามด้วยของแต่ละสาขาตามลำดับสาขา ในกลุ่มเดียวกันใช้ลำดับที่คลินิกตั้ง
- ป้ายบนการ์ดคือชื่อรายการที่คลินิกตั้ง (เช่น "สายด่วน 24 ชม.") คลินิกหลายสาขาต่อชื่อสาขาให้ ถ้าชื่อรายการยังไม่มีชื่อสาขา
- ถ้าไม่มีรายการ `emergency` เลย ใช้เบอร์หลักของคลินิกแทน (รายการ `phone` แรกของทั้งคลินิก ถ้าไม่มีใช้ `phone` แรกที่มี) ป้ายเขียนว่า "เบอร์คลินิก"
- ถ้าไม่มีเบอร์เลย หรืออ่าน API ไม่ได้ หน้าบอกให้ไปดูช่องทางอื่นที่หน้าติดต่อเรา

เพิ่มหรือแก้เบอร์ฉุกเฉินที่หน้า **ข้อมูลติดต่อ** ในหน้าจอพนักงาน เลือกชนิด "ฉุกเฉิน" ดู [ข้อมูลติดต่อ](contact.md)

## คำนวณว่าเปิดอยู่ไหม

อ่านจาก `GET /clinic/hours` (เวลาทำการรายสัปดาห์และวันหยุดที่ยังมาไม่ถึง) และ `GET /clinic/branches` คิดใน `features/emergency/lib/open-status.ts`

- คิดตามเวลาของคลินิก (Asia/Bangkok) ไม่ว่าเซิร์ฟเวอร์หรือเครื่องของผู้เยี่ยมชมตั้งเขตเวลาอะไร
- คิดทุกครั้งที่มีคนเปิดหน้า (`dynamic = 'force-dynamic'`) ไม่มีค่าที่ค้างจากตอน build
- เวลาทำการตั้งครั้งเดียวใช้ทุกสาขา วันหยุดที่ไม่ระบุสาขาปิดทุกสาขา วันหยุดที่ระบุสาขาปิดเฉพาะสาขานั้น
- เปิดอยู่ คือเวลาตอนนี้ตั้งแต่เวลาเปิดถึงก่อนเวลาปิดของวันนี้ และวันนี้ไม่ใช่วันหยุดของสาขานั้น
- ปิดอยู่ หาวันเปิดครั้งถัดไปไม่เกิน 14 วันข้างหน้า ข้ามวันที่ปิดทั้งวันและวันหยุด ถ้าไม่พบบอกให้โทรสอบถาม
- คลินิกสาขาเดียว หรืออ่านรายชื่อสาขาไม่ได้ แสดงการ์ดเดียวไม่มีชื่อสาขา
- คลินิกยังไม่ได้ตั้งเวลาทำการ หรืออ่านไม่ได้ หน้าบอกให้โทรสอบถามเวลาทำการ

backend บังคับให้เวลาปิดอยู่หลังเวลาเปิดในวันเดียวกัน จึงไม่มีวันที่เปิดข้ามเที่ยงคืน หน้านี้ไม่ได้บอกว่าสายด่วนรับสายตลอด 24 ชั่วโมง ข้อนั้นอยู่ที่ชื่อรายการที่คลินิกตั้งเอง

## เนื้อหาทางการแพทย์และการตรวจ

ไฟล์ข้อมูลคือ `frontend/src/features/emergency/content/emergency-care.ts` มีสามรายการ

| รายการ | ใช้ที่ |
|---|---|
| `warningSigns` | อาการที่ต้องพาไปหาหมอทันที ได้แก่ กินของมีพิษ หายใจลำบาก ชัก เลือดออกมาก ถูกรถชนหรือตกจากที่สูง ฉี่ไม่ออก ท้องอืดแข็งในสุนัข ล้มฟุบหรือหมดสติ บาดเจ็บที่ตา ฮีทสโตรก และคลอดยาก |
| `onTheWay` | สิ่งที่ควรทำระหว่างทาง ได้แก่ โทรก่อน ให้น้องอยู่นิ่ง ให้น้องอบอุ่น (ยกเว้นฮีทสโตรก) เอาบรรจุภัณฑ์ของที่น้องกินมาด้วย และกดแผลที่เลือดออก |
| `doNot` | สิ่งที่ไม่ควรทำ ได้แก่ อย่าทำให้อาเจียนเองถ้าสัตวแพทย์ยังไม่แนะนำ อย่าให้ยาของคน อย่าเอาของใส่ปากตอนชัก และอย่ารอดูอาการข้ามคืน |

ไม่มีชื่อยา ไม่มีขนาดยา และทุกข้อจบที่ให้โทรหาคลินิกและพาน้องมา

สิ่งที่เขียนเองและต้องให้สัตวแพทย์ยืนยันหรือแก้ (มีรายการเดียวกันในหัวไฟล์)

- รายการอาการและตัวอย่างของแต่ละอาการ เช่น ฉี่ไม่ออกในแมวตัวผู้ ท้องอืดในสุนัขพันธุ์ใหญ่อกลึก และคลอดยากเมื่อเบ่งแรงนานเกิน 30 นาที
- ให้น้องอบอุ่นระหว่างทาง ยกเว้นฮีทสโตรกที่ให้เช็ดตัวด้วยน้ำธรรมดาและเปิดแอร์หรือพัดลม ห้ามใช้น้ำแข็ง
- กดแผลด้วยผ้าสะอาด และวางผืนใหม่ทับเมื่อผ้าชุ่มเลือด
- ยกน้องที่อาจกระดูกหักหรือบาดเจ็บหลังด้วยแผ่นกระดานหรือผ้าผืนใหญ่
- การดูแลตอนชัก คือไม่เอาอะไรใส่ปาก ย้ายของแข็งออก หรี่ไฟ และจดเวลาที่เริ่มชัก
- ยกพาราเซตามอลเป็นตัวอย่างยาของคนที่อันตรายต่อแมว

บรรทัดล่างสุดของกล่องหมายเหตุอ่านจาก `clinicalReview` แบบเดียวกับ `scheduleReview` ของ [ตารางวัคซีนน้อง](vaccine-schedule.md)

- ยังว่าง หน้าเขียนว่า "เนื้อหาในหน้านี้อยู่ระหว่างรอสัตวแพทย์ของคลินิกตรวจทาน"
- ใส่ `reviewedBy` (ชื่อสัตวแพทย์) และ `reviewedOn` (วันที่ รูปแบบ `YYYY-MM-DD`) แล้ว หน้าเขียนว่าใครตรวจเมื่อไร

## ลิงก์มาที่หน้านี้

- **แถบสีแดงเหนือ footer** ต่อท้ายคำอธิบายสายด่วนด้วยลิงก์ "อาการแบบไหนต้องรีบมา" (`emergency.more` ใน `frontend/src/config/site-footer.ts`) แถบนี้ขึ้นเฉพาะเมื่อคลินิกมีเบอร์ฉุกเฉิน
- **แถวลิงก์ใน footer** ลิงก์ "กรณีฉุกเฉิน" (`footerLinks` ในไฟล์เดียวกัน)
- **ผู้ช่วย AI บนหน้าเว็บ** ต่อท้ายคำเตือนใต้ช่องพิมพ์ด้วยลิงก์ "ดูเบอร์ฉุกเฉินและอาการที่ต้องรีบมา" (`emergencyLink` ใน `features/assistant/content/assistant-widget.ts`) เป็นการแก้ฝั่งหน้าเว็บอย่างเดียว คำสั่งและคำตอบของผู้ช่วยฝั่ง backend ไม่ได้เปลี่ยน ดู [ผู้ช่วย AI บนหน้าเว็บ](assistant.md)
- **header** ปุ่มสีแดง **ฉุกเฉิน** มีไอคอนโทรศัพท์ อยู่ทางขวาข้างปุ่มเข้าสู่ระบบ ขึ้นทุกขนาดจอ ไม่ได้อยู่ในแถวเมนู เพราะแถวเมนูบนจอกว้างเต็มแล้ว ต่ำกว่า 640 px เหลือแต่ไอคอนข้างปุ่มเมนู ตรวจแล้วที่ความกว้าง 1280, 1024 และ 390 px ว่าไม่ชนและไม่ตัดบรรทัด ลิงก์และคำที่โปรแกรมอ่านหน้าจออ่านอยู่ที่ `emergencyLink` ใน `frontend/src/config/site-navigation.ts` ตัวปุ่มคือ `frontend/src/components/layout/site-header/emergency-link.tsx`

## SEO

- ชื่อแท็บและคำอธิบายอยู่ที่ `emergencyPage.meta` ผ่าน `pageMetadata` แบบหน้าอื่น
- อยู่ใน `/sitemap.xml` (`sitePages.emergency` ใน `features/seo/content/seo.ts`)
- structured data สามชุด คือ `ClinicJsonLd` (คลินิก) `BreadcrumbJsonLd` และ `EmergencyJsonLd` ซึ่งเป็น `EmergencyService` และ `VeterinaryCare` มี `telephone` เป็นเบอร์แรกที่หน้าแสดง ที่อยู่ พิกัด แผนที่ เวลาทำการ และวันหยุด เอามาจาก `clinicSchema` ตัวเดียวกับของคลินิก และชี้กลับไปที่คลินิกด้วย `parentOrganization` ดู [SEO](../seo.md)
