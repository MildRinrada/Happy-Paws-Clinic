# บริการ

รายการบริการที่คลินิกขาย เช่น ตรวจสุขภาพ วัคซีน ขูดหินปูน แต่ละบริการมีหมวด ระยะเวลา ราคา ผู้ให้บริการที่ทำได้ และกติกาว่าลูกค้าจองเองบนเว็บได้หรือไม่ ระยะเวลาของบริการคือสิ่งที่ตัดสินว่านัดสองนัดชนกันหรือไม่ ราคาคือราคาตั้งที่แสดงบนเว็บ

## ใครใช้

| ใคร | ทำอะไร |
|---|---|
| ผู้เยี่ยมชมเว็บ | ดูเมนูบริการที่เปิดจองออนไลน์ (`GET /services`) และจองเอง |
| พนักงานต้อนรับ | จองบริการที่เคาน์เตอร์ ได้ทั้งบริการที่เปิดและไม่เปิดจองออนไลน์ |
| ผู้ดูแลบริการ (`service:manage`) | เพิ่มบริการ แก้ข้อมูล ตั้งราคา และกำหนดการจองออนไลน์ ที่หน้า **บริการและราคา** |

## หมวด

หกหมวดตายตัวตาม contract คือ ตรวจ วัคซีน ทันตกรรม ผ่าตัด แล็บ กรูมมิ่ง (`GET /services/categories`) คลินิกเพิ่มหมวดเองไม่ได้ ([assumptions.md § 28](../assumptions.md))

## ราคา

ราคาเปลี่ยนแบบตั้งล่วงหน้า ไม่ใช่เขียนทับ ราคาแต่ละชุดมีวันที่มีผล ระบบใช้ชุดล่าสุดที่ถึงวันแล้ว ชุดที่ยังไม่ถึงวันเก็บไว้รอ และราคาเก่ายังอยู่ในระบบ ถ้าบันทึกราคาซ้ำในวันที่มีชุดอยู่แล้ว ชุดใหม่แทนชุดเดิมของวันนั้น

ราคาหนึ่งชุดมีราคาพื้นฐาน และราคาแยกได้หลายแถว แต่ละแถวระบุชนิดสัตว์ ช่วงน้ำหนัก หรือทั้งสองอย่าง น้ำหนักสูงสุดไม่นับรวม เช่น 0 ถึง 10 กก. คือน้ำหนักไม่ถึง 10 กก.

## การจองออนไลน์

| ค่า | มีผลกับ |
|---|---|
| เปิดให้ลูกค้าจองเอง | เว็บสาธารณะเท่านั้น เคาน์เตอร์จองได้เสมอ บริการใหม่ปิดไว้ก่อนจนกว่าจะเปิด |
| สาขาที่มีบริการ | ทั้งเคาน์เตอร์และออนไลน์ ไม่เลือกคือทุกสาขา |
| ช่วงเวลาที่ลูกค้าจองเองได้ | เว็บสาธารณะเท่านั้น นับจากเวลาเริ่มนัด ไม่ใส่คือทุกช่วงที่หมออยู่เวร |

## ปิดใช้งาน

บริการที่ปิดใช้งานจองใหม่ไม่ได้ทั้งเคาน์เตอร์และออนไลน์ และหายจากเมนูบนเว็บ แต่ไม่ถูกลบ นัดและบิลเดิมยังอ้างถึงได้ เปิดใช้งานกลับได้ทุกเมื่อ

## หน้าจอพนักงาน

`/settings/services` แท็บ **บริการและราคา** ในหน้าตั้งค่า เห็นเฉพาะบัญชีที่ถือ `service:manage`

- บริการแบ่งการ์ดตามหมวด ตามลำดับของ contract บริการที่เปิดใช้งานขึ้นก่อน
- แต่ละแถวบอกชื่อ ระยะเวลา ราคาที่ใช้วันนี้ และป้าย **จองออนไลน์ได้** **จองที่เคาน์เตอร์เท่านั้น** **ปิดใช้งาน** หรือ **ราคาแยก N แบบ** ถ้ามีราคาชุดใหม่รอวันมีผล แถวบอกราคาและวันที่เริ่ม
- **แก้ไขข้อมูล** ชื่อ หมวด ระยะเวลา ผู้ให้บริการ (เลือกจากรายชื่อพนักงาน ไม่เลือกคือหมอทุกคนที่อยู่เวร) และเปิดหรือปิดใช้งาน
- **ราคา** ราคาพื้นฐาน วันที่มีผล (ตั้งต้นที่วันนี้) และแถวราคาแยก ฟอร์มเริ่มจากราคาชุดที่ใช้อยู่
- **การจองออนไลน์** เปิดหรือปิด สาขาที่มีบริการ (ขึ้นเมื่อคลินิกมีมากกว่าหนึ่งสาขา) และช่วงเวลารายสัปดาห์
- **เพิ่มบริการ** ชื่อ หมวด ระยะเวลา ราคาเริ่มต้น รหัสบริการ (ไม่บังคับ กลายเป็น id เช่น `svc_checkup`) และเลือกได้ว่าจะเปิดจองออนไลน์ทันทีหรือไม่

เปิดฟอร์มได้ทีละอันต่อแถว บันทึกแล้วแถวโหลดข้อมูลใหม่และปิดฟอร์มเอง รายชื่อผู้ให้บริการต้องถือ `staff:read` ด้วย ถ้าไม่ถือ ฟอร์มบอกว่าเปลี่ยนผู้ให้บริการไม่ได้ ส่วนอื่นยังแก้ได้

## API

| Method | Endpoint | Scope |
|---|---|---|
| GET | `/services?category=&branch=` | สาธารณะ เฉพาะบริการที่เปิดใช้งานและเปิดจองออนไลน์ |
| GET | `/services/categories` | สาธารณะ |
| GET | `/staff/services?category=` | `service:manage` ทุกบริการ ส่วนขยาย |
| POST | `/staff/services` | `service:manage` |
| PATCH | `/staff/services/{id}` | `service:manage` ชื่อ หมวด ระยะเวลา ผู้ให้บริการ เปิดใช้งาน ส่วนขยาย |
| PATCH | `/staff/services/{id}/pricing` | `service:manage` |
| PATCH | `/staff/services/{id}/availability` | `service:manage` |

สองเส้นที่เป็นส่วนขยายได้รับอนุมัติก่อนสร้าง ดู [contract-extensions.md § 17](../contract-extensions.md) การเขียนทุกเส้นรองรับ `If-Match` ค่าที่ผิดได้ `422` ที่ช่องนั้น รหัสบริการซ้ำได้ `409 duplicate_service`

## ข้อจำกัด

- **หน้าจองที่เคาน์เตอร์ยังเลือกได้เฉพาะบริการที่เปิดจองออนไลน์** เพราะใช้เมนูสาธารณะ รายการเต็มต้องใช้ `service:manage` ซึ่งพนักงานต้อนรับไม่มี ([assumptions.md § 27](../assumptions.md))
- **ราคาในแคตตาล็อกยังไม่ถูกคัดลอกไปใส่บิลอัตโนมัติ** บรรทัดในใบแจ้งหนี้มีราคาต่อหน่วยของตัวเอง
- ลบบริการไม่ได้ ใช้ปิดใช้งานแทน
