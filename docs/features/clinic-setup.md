# ตั้งค่าคลินิก

ข้อมูลคลินิก สาขา เวลาทำการ วันหยุด และกติกาการทำงานสามชุด คือการจองนัด เลขคิว และเวชระเบียน ทั้งหมดแก้ได้จากหน้า **ตั้งค่า** ของพนักงาน โดยไม่ต้องใช้คำสั่งหรือเรียก API เอง

## ใครใช้

| ใคร | ทำอะไร |
|---|---|
| เจ้าของและผู้ดูแลคลินิก (`settings:write`) | แก้ทุกอย่างในหน้านี้ |
| ผู้เยี่ยมชมเว็บ | เห็นชื่อ ใบอนุญาต สาขา เวลาทำการ และวันหยุด บนหน้าสาธารณะ |
| ผู้ดูแลเซิร์ฟเวอร์ | สร้างเจ้าของคนแรกและสาขาแรกด้วยคำสั่ง `bootstrap` ซึ่งทำผ่านหน้าจอไม่ได้ เพราะยังไม่มีใครเข้าสู่ระบบได้ |

## หน้าตั้งค่า

เมนู **ตั้งค่า** ขึ้นให้บัญชีที่ถือ `settings:write` หรือ `service:manage` เปิดแล้วพาไปแท็บแรกที่บัญชีนั้นใช้ได้ แท็บที่ใช้ไม่ได้จะไม่แสดง

| แท็บ | ที่อยู่ | scope |
|---|---|---|
| คลินิกและสาขา | `/settings/clinic` | `settings:write` |
| เวลาทำการและวันหยุด | `/settings/hours` | `settings:write` |
| กติกาการจอง คิว และเวชระเบียน | `/settings/rules` | `settings:write` |
| บริการและราคา | `/settings/services` | `service:manage` ดู [บริการ](services.md) |
| ข้อมูลติดต่อ | `/settings/contacts` | `settings:write` ดู [ข้อมูลติดต่อ](contact.md) |
| ประกาศความเป็นส่วนตัว | `/settings/privacy-policy` | `settings:read` ดู แก้ร่างต้องมี `settings:write` เผยแพร่ต้องมี `settings:danger` ดู [ประกาศความเป็นส่วนตัวของคลินิก](privacy-policy.md) |
| บทความ | `/settings/articles` | `content:manage` ดู [บทความ](articles.md) |

ทุกฟอร์มบันทึกแยกกัน กดบันทึกแล้วขึ้นคำว่า **บันทึกแล้ว** ข้างปุ่ม ถ้าข้อมูลผิด ข้อความภาษาไทยจาก API ขึ้นใต้ช่องที่ผิด ถ้ามีคนอื่นบันทึกไปก่อน (`409`) หน้าจอบอกให้โหลดหน้าใหม่ก่อนแก้อีกครั้ง

## คลินิกและสาขา

**ข้อมูลคลินิก** ชื่อ สีหลัก (เลือกจากจานสีหรือพิมพ์ `#RRGGBB`) ลิงก์รูปโลโก้ เลขที่ใบอนุญาต และผู้ดำเนินการสถานพยาบาล ส่งทุกช่องไป `PATCH /clinic` ช่องที่เว้นว่างคือการล้างค่านั้น ชื่อและใบอนุญาตขึ้นบนหน้าสาธารณะทันทีหลังบันทึก

**สาขา** แสดงสาขาที่เปิดอยู่ พร้อมรหัส ที่อยู่ ห้องตรวจ และพิกัด ปุ่ม **เปิดสาขาใหม่** รับรหัส (a-z 0-9 _ - ยาว 2 ถึง 32 ตัว กลายเป็น id เช่น `brn_thonglor`) ชื่อ ที่อยู่ พิกัด และห้องตรวจที่คั่นด้วยจุลภาค

## เวลาทำการและวันหยุด

**เวลาทำการรายสัปดาห์** เจ็ดแถว ใส่เวลาเปิดปิด หรือติ๊ก **ปิดทั้งวัน** ปุ่ม **ใช้เวลาวันจันทร์กับทุกวันที่เปิด** คัดลอกเวลาไปวันอื่น บันทึกครั้งเดียวทั้งสัปดาห์ด้วย `PUT /clinic/hours` ถ้าคลินิกยังไม่เคยตั้ง หน้าจอเริ่มจาก 09:00 ถึง 18:00 ทุกวัน และเตือนว่าเว็บยังไม่แสดงเวลา

เวลาทำการเป็นข้อมูลที่แสดงบนเว็บเท่านั้น เวลาที่จองได้จริงมาจาก [ตารางเวร](schedules.md)

**วันหยุดพิเศษ** แสดงวันหยุดที่กำลังจะมาถึง พร้อมป้ายว่าปิดทุกสาขาหรือสาขาเดียว ปุ่ม **เพิ่มวันหยุด** รับวันที่ (วันนี้หรือหลังจากนี้) ชื่อวันหยุด และสาขา วันที่ประกาศแล้วปิดรับนัดใหม่ทันที นัดที่มีอยู่แล้วไม่ถูกยกเลิก

## กติกาการจอง คิว และเวชระเบียน

| ฟอร์ม | ช่อง |
|---|---|
| การจองนัด | ความยาวช่องเวลา (5 ถึง 120 นาที ทีละ 5) จองล่วงหน้าอย่างน้อยกี่นาที ลูกค้ายกเลิกเองได้ก่อนนัดกี่ชั่วโมง จองล่วงหน้าได้ไม่เกินกี่วัน และโควตา walk-in |
| เลขคิว | ตัวอักษรนำหน้า (A-Z ไม่เกิน 3 ตัว) จำนวนหลัก (2 ถึง 5) และเริ่มนับใหม่ทุกวัน มุมขวาบนแสดงตัวอย่างเลขคิวที่ 14 ของวันซึ่ง API คำนวณให้ |
| เวชระเบียน | ส่วนที่ต้องกรอกก่อนปิดเคส ระบบในแบบฟอร์มตรวจร่างกาย (หนึ่งบรรทัดต่อหนึ่งระบบ) ส่วนที่เจ้าของเห็นใน portal และให้เฉพาะหมอเจ้าของเคสเซ็น |

กติกาใหม่มีผลกับนัด บัตรคิว และเคสที่เกิดหลังบันทึก ของเดิมไม่เปลี่ยน การแก้ฟอร์มเวชระเบียนถูกบันทึกลง audit log สองฟอร์มอื่นไม่ถูกบันทึก

โควตา walk-in เก็บไว้และแสดงได้ แต่ระบบยังไม่ได้ใช้กันช่องเวลา หน้าจอเขียนบอกไว้ใต้ช่อง

## API

| Method | Endpoint | ใช้ที่ |
|---|---|---|
| GET | `/clinic`, `/clinic/branches`, `/clinic/hours` | อ่านค่าปัจจุบัน (สาธารณะ) |
| PATCH | `/clinic` | ข้อมูลคลินิก |
| POST | `/clinic/branches` | เปิดสาขาใหม่ |
| PUT | `/clinic/hours` | เวลาทำการทั้งสัปดาห์ |
| POST | `/clinic/holidays` | วันหยุดพิเศษ |
| GET, PATCH | `/clinic/settings/booking` | การจองนัด |
| PATCH | `/clinic/settings/queue` | เลขคิว |
| PATCH | `/clinic/settings/medical-record` | เวชระเบียน |

contract ไม่มี `GET` ของค่าตั้งคิวและเวชระเบียน หน้าจอจึงอ่านด้วย `PATCH` ที่ body ว่าง ซึ่งไม่เปลี่ยนอะไร ([assumptions.md § 27](../assumptions.md)) การเขียนทุกเส้นส่ง `If-Match` ด้วย version ที่อ่านมา และเก็บ version ใหม่จากคำตอบไว้ใช้กับการบันทึกครั้งถัดไปในหน้าเดิม

## ข้อจำกัด

- **แก้หรือปิดสาขาเดิมไม่ได้** contract มีแค่ `POST /clinic/branches` หน้าจอเขียนบอกไว้ใต้รายการสาขา
- **ลบวันหยุดที่ประกาศแล้วไม่ได้** contract มีแค่ `POST /clinic/holidays` หน้าจอเตือนให้ตรวจวันที่ก่อนกดเพิ่ม
- วันหยุดที่ผ่านไปแล้วไม่ขึ้นในรายการ เพราะ `GET /clinic/hours` คืนเฉพาะวันที่กำลังจะมาถึง
