# ตั้งค่าคลินิก

ข้อมูลคลินิก สาขา เวลาทำการ วันหยุด และกติกาการทำงานสามชุด คือการจองนัด เลขคิว และเวชระเบียน ทั้งหมดแก้ได้จากหน้า **ตั้งค่า** ของพนักงาน โดยไม่ต้องใช้คำสั่งหรือเรียก API เอง

## ใครใช้

| ใคร | ทำอะไร |
|---|---|
| เจ้าของและผู้ดูแลคลินิก (`settings:write`) | แก้ทุกอย่างในหน้านี้ |
| ผู้เยี่ยมชมเว็บ | เห็นชื่อ ใบอนุญาต สาขา เวลาทำการ และวันหยุด บนหน้าสาธารณะ |
| ผู้ดูแลเซิร์ฟเวอร์ | สร้างเจ้าของคนแรกและสาขาแรกด้วยคำสั่ง `bootstrap` ซึ่งทำผ่านหน้าจอไม่ได้ เพราะยังไม่มีใครเข้าสู่ระบบได้ |

## หน้าตั้งค่า

เมนู **ตั้งค่า** ขึ้นให้บัญชีที่ใช้หน้าตั้งค่าได้อย่างน้อยหนึ่งหน้า เปิดแล้วพาไปหน้าแรกที่บัญชีนั้นใช้ได้ตามลำดับในตารางด้านล่าง หน้าที่ใช้ไม่ได้จะไม่แสดง และกลุ่มที่ไม่เหลือหน้าไหนเลยก็ไม่แสดง

| กลุ่ม | หน้า | ที่อยู่ | scope |
|---|---|---|---|
| คลินิก | คลินิกและสาขา | `/settings/clinic` | `settings:write` |
| คลินิก | เวลาทำการและวันหยุด | `/settings/hours` | `settings:write` |
| คลินิก | ข้อมูลติดต่อ | `/settings/contacts` | `settings:write` ดู [ข้อมูลติดต่อ](contact.md) |
| การจองและการรักษา | กติกาการจอง คิว และเวชระเบียน | `/settings/rules` | `settings:write` |
| การจองและการรักษา | นโยบายยกเลิกและประเภทนัด | `/settings/appointments` | `settings:write` |
| การจองและการรักษา | บริการและราคา | `/settings/services` | `service:manage` ดู [บริการ](services.md) |
| ทีมงาน | พนักงานและสิทธิ์ | `/settings/staff` | `staff:read` |
| ลูกค้าและเว็บไซต์ | แต้มสะสม | `/settings/loyalty` | `settings:write` |
| ลูกค้าและเว็บไซต์ | รีวิวจากลูกค้า | `/settings/reviews` | `content:manage` |
| ลูกค้าและเว็บไซต์ | บทความ | `/settings/articles` | `content:manage` ดู [บทความ](articles.md) |
| ลูกค้าและเว็บไซต์ | ประกาศความเป็นส่วนตัว | `/settings/privacy-policy` | `settings:read` ดู แก้ร่างต้องมี `settings:write` เผยแพร่ต้องมี `settings:danger` ดู [ประกาศความเป็นส่วนตัวของคลินิก](privacy-policy.md) |
| เชื่อมต่อ | LINE | `/settings/line` | `integration:manage` |
| เชื่อมต่อ | เชื่อมต่อระบบ | `/settings/integrations` | `integration:manage` |

**รายการหน้าตั้งค่า** จอกว้างตั้งแต่ 1024 px มีรายการหน้าแบ่งตามกลุ่มอยู่ด้านซ้ายของพื้นที่ตั้งค่า (ไม่ใช่เมนูหลักของพนักงาน) หน้าที่เปิดอยู่มีพื้นสีและบอกโปรแกรมอ่านหน้าจอด้วย `aria-current` บนโทรศัพท์มีช่องเลือก **หน้าตั้งค่า** ช่องเดียวเหนือหน้า แบ่งตามกลุ่มเหมือนกัน

**จุดเตือน** หน้าที่ยังต้องตั้งค่ามีจุดสีส้มหลังชื่อ โปรแกรมอ่านหน้าจออ่านว่า "ต้องตั้งค่า" และบนโทรศัพท์คำนี้ต่อท้ายชื่อในช่องเลือก ตอนนี้มีหน้าเดียวคือ **ประกาศความเป็นส่วนตัว** เมื่อคลินิกยังไม่ได้เผยแพร่ประกาศ อ่านจาก `GET /privacy-policy` เส้นเดียวกับที่เตือนบนหน้าภาพรวม (เก็บไว้หนึ่งนาที) หน้าอื่นยังไม่มีจุด เพื่อไม่ให้ทุกหน้าตั้งค่าต้องอ่าน API เพิ่มหลายเส้น อ่านไม่ได้ก็ไม่มีจุด

**แถบบันทึก** ฟอร์มตั้งค่าที่มีปุ่มบันทึกปุ่มเดียวไม่มีปุ่มบันทึกของตัวเองแล้ว พอแก้ช่องไหนก็ตาม แถบ **มีการแก้ไขที่ยังไม่บันทึก** ขึ้นที่ด้านล่างของจอ บอกชื่อส่วนที่แก้ พร้อมปุ่ม **ยกเลิก** (กลับไปเป็นค่าที่บันทึกไว้) และ **บันทึก** แก้กลับเป็นค่าเดิมเองแถบก็หายไป

- หน้าที่มีหลายฟอร์ม (กติกาการจอง คิว และเวชระเบียน หรือนโยบายยกเลิกและประเภทนัด) ใช้แถบเดียว แถบบอกว่ามีกี่ส่วนที่แก้และชื่ออะไร **บันทึก** ส่งทุกส่วนที่แก้ แยกคำขอกันส่วนละหนึ่งคำขอ **ยกเลิก** คืนค่าทุกส่วน
- ผลของการบันทึกขึ้นที่ท้ายฟอร์มของส่วนนั้น คือคำว่า **บันทึกแล้ว** หรือข้อความภาษาไทยจาก API ใต้ช่องที่ผิด ถ้ามีคนอื่นบันทึกไปก่อน (`409`) หน้าจอบอกให้โหลดหน้าใหม่ก่อนแก้อีกครั้ง ส่วนที่บันทึกไม่ผ่านยังอยู่ในแถบ และแถบบอกว่าให้ดูข้อความที่ส่วนไหน
- ระหว่างที่ยังไม่บันทึก ถ้ากดลิงก์ไปหน้าอื่นในระบบพนักงาน หรือเปลี่ยนหน้าจากช่องเลือกบนโทรศัพท์ ระบบถามก่อนว่าจะออกเลยไหม ถ้าโหลดหน้าใหม่ ปิดแท็บ หรือพิมพ์ที่อยู่ใหม่ เบราว์เซอร์ถามเอง
- ฟอร์มที่ใช้แถบ ได้แก่ ข้อมูลคลินิกและโลโก้ เวลาทำการรายสัปดาห์ การจองนัด เลขคิว เวชระเบียน นโยบายยกเลิก ประเภทนัด แต้มสะสม LINE ผู้ให้บริการรับชำระเงิน และแล็บภายนอก
- ตัวแก้บทความและตัวแก้ร่างประกาศความเป็นส่วนตัวยังมีปุ่มบันทึกของตัวเอง เพราะอยู่คู่กับปุ่มอื่นอย่างเผยแพร่ แต่ยังถามก่อนออกจากหน้าเหมือนกัน
- ฟอร์มเพิ่มของใหม่ (สาขา วันหยุด บริการ พนักงาน บทบาท ช่องทางติดต่อ webhook API key) และฟอร์มที่แก้ของทีละรายการในรายการยาว (บริการแต่ละตัว พนักงานแต่ละคน บทบาท ช่องทางติดต่อ webhook) ยังมีปุ่มของตัวเองและไม่ถามก่อนออก เพราะแต่ละอันบันทึกของชิ้นเดียว ถ้ารวมทุกแถวไว้ในแถบเดียว จะไม่ชัดว่ากดบันทึกแล้วอะไรถูกบันทึก

## คลินิกและสาขา

หน้านี้มีสามการ์ด สองการ์ดแรกเป็นฟอร์มเดียวกันที่บันทึกพร้อมกันด้วยแถบบันทึก ส่งทุกช่องไป `PATCH /clinic` ช่องที่เว้นว่างคือการล้างค่านั้น

**ข้อมูลคลินิก** ชื่อ เลขที่ใบอนุญาต และผู้ดำเนินการสถานพยาบาล ใต้แต่ละช่องบอกว่าค่านั้นไปแสดงที่ไหน

| ช่อง | แสดงที่ |
|---|---|
| ชื่อคลินิก | ข้างโลโก้บนหัวและท้ายหน้าเว็บ หน้าของลูกค้า หน้าเข้าสู่ระบบ และเมนูของพนักงาน (เมื่อเปิดแสดงชื่อหรือไม่มีโลโก้) ข้อมูลสำหรับเครื่องมือค้นหา (JSON-LD) หัวใบรับรองสุขภาพ ใบส่งตัว และสมุดวัคซีน ฉลากยา รายงานที่ส่งออก และหน้านโยบายความเป็นส่วนตัว |
| เลขที่ใบอนุญาต | หัวใบรับรองสุขภาพ ใบส่งตัว และสมุดวัคซีน ฉลากยา และหน้านโยบายความเป็นส่วนตัว |
| ผู้ดำเนินการสถานพยาบาล | หน้านโยบายความเป็นส่วนตัว ส่วน "ใครดูแลข้อมูลของคุณ" |

ช่อง **สีหลักของคลินิก** ถูกเอาออกจากฟอร์ม เพราะหน้าเว็บไม่ได้ใช้ค่านี้ ฟอร์มยังส่งค่าที่เก็บไว้กลับไปตามเดิม ค่าเดิมจึงไม่ถูกล้าง

**โลโก้และไอคอน** ([ส่วนขยาย § 50](../contract-extensions.md)) โลโก้ที่ตั้งไว้ใช้แทนรูปอุ้งเท้าทุกที่ ทั้งหัวและท้ายหน้าเว็บ หัวหน้าลูกค้า หน้าเข้าสู่ระบบ และเมนูของพนักงาน

- **เลือกรูป** ลากไฟล์มาวางในกล่อง หรือกด **เลือกไฟล์** รับ PNG, JPEG หรือ WebP ไม่เกิน 5 MB รูปทรงไหนก็ได้ แนะนำ PNG พื้นใส ด้านยาวอย่างน้อย 512 px หน้าจอตรวจชนิดและขนาดก่อนส่ง และบอกเมื่อรูปเล็กกว่าที่แนะนำ ไม่รับ SVG
- **อัปโหลดทันที แต่ขึ้นเว็บตอนบันทึก** ไฟล์ถูกส่งไปที่เก็บไฟล์ผ่าน `POST /clinic/logo` ทันทีที่เลือก แต่หน้าเว็บเปลี่ยนเมื่อกด **บันทึก** เท่านั้น รูปที่เลือกแล้วไม่บันทึกจึงไม่ขึ้นเว็บ
- **ใช้โลโก้รูปอุ้งเท้าเดิม** ล้างโลโก้ บันทึกแล้วทุกหน้ากลับไปใช้รูปอุ้งเท้า
- **แสดงชื่อคลินิกข้างโลโก้** ขึ้นเฉพาะเมื่อมีโลโก้ (ที่บันทึกแล้วหรือที่เพิ่งเลือก) เพราะข้างรูปอุ้งเท้ามีชื่อเสมอ เปิดไว้ตั้งแต่ต้น ปิดเมื่อโลโก้มีชื่อคลินิกอยู่แล้ว ชื่อข้างโลโก้จะหายทุกที่ และโลโก้มีชื่อคลินิกเป็นข้อความแทนรูปให้โปรแกรมอ่านหน้าจอ
- **ขั้นสูง: ใช้รูปจากลิงก์** ช่องลิงก์ `https://` แบบเดิม สำหรับคลินิกที่ใส่ลิงก์ไว้ก่อนแล้ว
- **ตั้งไอคอนแท็บแยก (ไม่บังคับ)** ส่วนพับไว้ รับรูปสี่เหลี่ยมจัตุรัสสำหรับแท็บของเบราว์เซอร์และหน้าจอโทรศัพท์ (`POST /clinic/tab-icon`) บอกเมื่อรูปไม่เป็นสี่เหลี่ยมจัตุรัส ถ้าไม่ตั้ง ระบบย่อโลโก้ลงกรอบสี่เหลี่ยมให้ ถ้าไม่มีโลโก้ด้วย แท็บใช้รูปอุ้งเท้าเดิม
- **ตัวอย่าง** ข้างฟอร์มแสดงหัวหน้าเว็บแบบที่เลือกอยู่แบบเดียว ปุ่ม **ดูตัวอย่างทั้งหมด** เปิดหัวหน้าเว็บอีกแบบ (ป้ายบอกแบบที่เลือกอยู่) เมนูของพนักงาน และแท็บของเบราว์เซอร์ ทุกตัวอย่างวาดจากค่าในฟอร์ม ไม่ใช่ค่าที่บันทึกแล้ว

ทุกหน้าอ่านโลโก้จาก `GET /clinic` ที่แคชร่วมกันห้านาที การบันทึกล้างแคชนี้ทันที โลโก้ใหม่จึงขึ้นตั้งแต่คำขอถัดไป ถ้า API ล่ม ทุกหน้าใช้รูปอุ้งเท้าเหมือนเดิม

**สาขา** แสดงสาขาที่เปิดอยู่ พร้อมรหัส ที่อยู่ ห้องตรวจเป็นป้ายเล็ก ๆ และลิงก์ **เปิดในแผนที่** เมื่อมีพิกัด (Google Maps ที่ละติจูดและลองจิจูดนั้น เปิดในแท็บใหม่)

- **+ เปิดสาขาใหม่** บนหัวการ์ด เปิดฟอร์มในกล่อง รับรหัส (a-z 0-9 _ - ยาว 2 ถึง 32 ตัว กลายเป็น id เช่น `brn_thonglor`) ชื่อ ที่อยู่ พิกัด และห้องตรวจที่คั่นด้วยจุลภาค
- **แก้ไข** ข้างแต่ละสาขา ([ส่วนขยาย § 51](../contract-extensions.md)) เปิดกล่องแก้ชื่อ ที่อยู่ พิกัด และห้องตรวจ รหัสสาขาแสดงไว้แต่แก้ไม่ได้ เว้นที่อยู่ว่างคือล้างที่อยู่ เว้นพิกัดว่างทั้งสองช่องคือใช้พิกัดเดิม ห้องตรวจที่พิมพ์คือรายการทั้งหมดหลังแก้ ห้องที่ยังมีคิวค้างอยู่ (รอ ถูกเรียก ข้ามไว้ หรืออยู่ในห้อง ของวันนี้หรือหลังจากนี้) เอาออกไม่ได้ ระบบบอกเลขคิวที่ค้างใต้ช่องห้องตรวจ ถ้ามีคนแก้สาขานี้ไปก่อน ได้ข้อความให้โหลดหน้าใหม่

## เวลาทำการและวันหยุด

**เวลาทำการรายสัปดาห์** เจ็ดแถว ใส่เวลาเปิดปิด หรือติ๊ก **ปิดทั้งวัน** ปุ่ม **ใช้เวลาวันจันทร์กับทุกวันที่เปิด** คัดลอกเวลาไปวันอื่น บันทึกครั้งเดียวทั้งสัปดาห์ด้วย `PUT /clinic/hours` ถ้าคลินิกยังไม่เคยตั้ง หน้าจอเริ่มจาก 09:00 ถึง 18:00 ทุกวัน และเตือนว่าเว็บยังไม่แสดงเวลา

เวลาทำการเป็นข้อมูลที่แสดงบนเว็บเท่านั้น เวลาที่จองได้จริงมาจาก [ตารางเวร](schedules.md)

**วันหยุดพิเศษ** แสดงวันหยุดที่กำลังจะมาถึง พร้อมป้ายว่าปิดทุกสาขาหรือสาขาเดียว ปุ่ม **เพิ่มวันหยุด** รับวันที่ (วันนี้หรือหลังจากนี้) ชื่อวันหยุด และสาขา วันที่ประกาศแล้วปิดรับนัดใหม่ทันที นัดที่มีอยู่แล้วไม่ถูกยกเลิก

| ฟอร์ม | ช่อง |
|---|---|
| การจองนัด | ความยาวช่องเวลา (5 ถึง 120 นาที ทีละ 5) จองล่วงหน้าอย่างน้อยกี่นาที ลูกค้ายกเลิกเองได้ก่อนนัดกี่ชั่วโมง จองล่วงหน้าได้ไม่เกินกี่วัน และโควตา walk-in |
| เลขคิว | ตัวอักษรนำหน้า (A-Z ไม่เกิน 3 ตัว) จำนวนหลัก (2 ถึง 5) และเริ่มนับใหม่ทุกวัน มุมขวาบนแสดงตัวอย่างเลขคิวที่ 14 ของวันซึ่ง API คำนวณให้ |
| เวชระเบียน | ส่วนที่ต้องกรอกก่อนปิดเคส ระบบในแบบฟอร์มตรวจร่างกาย (หนึ่งบรรทัดต่อหนึ่งระบบ) ส่วนที่เจ้าของเห็นใน portal และให้เฉพาะหมอเจ้าของเคสเซ็น |

กติกาใหม่มีผลกับนัด บัตรคิว และเคสที่เกิดหลังบันทึก ของเดิมไม่เปลี่ยน การแก้ฟอร์มเวชระเบียนถูกบันทึกลง audit log สองฟอร์มอื่นไม่ถูกบันทึก

โควตา walk-in เก็บไว้และแสดงได้ แต่ระบบยังไม่ได้ใช้กันช่องเวลา หน้าจอเขียนบอกไว้ใต้ช่อง

## API

| Method | Endpoint | ใช้ที่ |
|---|---|---|
| GET | `/clinic`, `/clinic/branches`, `/clinic/hours` | อ่านค่าปัจจุบัน (สาธารณะ) |
| PATCH | `/clinic` | ข้อมูลคลินิก โลโก้ ไอคอนแท็บ และการแสดงชื่อข้างโลโก้ |
| POST | `/clinic/logo`, `/clinic/tab-icon` | ขอ URL สำหรับส่งไฟล์โลโก้หรือไอคอนแท็บ ([§ 50](../contract-extensions.md)) |
| GET | `/clinic/logo`, `/clinic/tab-icon` | ที่อยู่สาธารณะของรูปที่อัปโหลด ส่งต่อไปที่ลิงก์ที่ลงชื่อแล้ว |
| POST | `/clinic/branches` | เปิดสาขาใหม่ |
| PATCH | `/clinic/branches/{id}` | แก้สาขา ([§ 51](../contract-extensions.md)) |
| PUT | `/clinic/hours` | เวลาทำการทั้งสัปดาห์ |
| POST | `/clinic/holidays` | วันหยุดพิเศษ |
| GET, PATCH | `/clinic/settings/booking` | การจองนัด |
| PATCH | `/clinic/settings/queue` | เลขคิว |
| PATCH | `/clinic/settings/medical-record` | เวชระเบียน |

contract ไม่มี `GET` ของค่าตั้งคิวและเวชระเบียน หน้าจอจึงอ่านด้วย `PATCH` ที่ body ว่าง ซึ่งไม่เปลี่ยนอะไร ([assumptions.md § 27](../assumptions.md)) การเขียนทุกเส้นส่ง `If-Match` ด้วย version ที่อ่านมา และเก็บ version ใหม่จากคำตอบไว้ใช้กับการบันทึกครั้งถัดไปในหน้าเดิม

## ข้อจำกัด

- **ปิดสาขาและแก้รหัสสาขาไม่ได้** § 51 แก้ได้แค่ชื่อ ที่อยู่ พิกัด และห้องตรวจ และลบพิกัดออกจากสาขาไม่ได้ เปลี่ยนเป็นพิกัดใหม่ได้อย่างเดียว
- **ไม่ถามก่อนออกตอนกดปุ่มย้อนกลับของเบราว์เซอร์** Next.js ไม่มีทางหยุดการย้อนกลับไว้ได้ ระบบถามเฉพาะตอนกดลิงก์ ใช้ช่องเลือกหน้าบนโทรศัพท์ โหลดหน้าใหม่ หรือปิดแท็บ
- **ลบวันหยุดที่ประกาศแล้วไม่ได้** contract มีแค่ `POST /clinic/holidays` หน้าจอเตือนให้ตรวจวันที่ก่อนกดเพิ่ม
- วันหยุดที่ผ่านไปแล้วไม่ขึ้นในรายการ เพราะ `GET /clinic/hours` คืนเฉพาะวันที่กำลังจะมาถึง
- **ไม่มีโลโก้แยกสำหรับพื้นเข้ม** ท้ายหน้าเว็บพื้นสีเข้ม โลโก้สีเข้มบนพื้นใสอาจอ่านยาก
- จอเรียกคิว อีเมล และรูปตอนแชร์ลิงก์ยังไม่ใช้โลโก้ของคลินิก
