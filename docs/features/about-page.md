# หน้าเกี่ยวกับคลินิก

หน้า `/about` บนเว็บสาธารณะ เปิดได้จากเมนู **เกี่ยวกับคลินิก** ที่ header และลิงก์ใน footer ไม่ต้องเข้าสู่ระบบ

## มีอะไรบ้าง

เรียงจากบนลงล่าง

| ส่วน | ข้อมูลมาจาก |
|---|---|
| หัวหน้าเพจพร้อมรูป | ไฟล์ content |
| เรื่องราวของคลินิกและเส้นทางตามปี | ไฟล์ content |
| สิ่งที่เรายึดถือ | ไฟล์ content ของหน้าแรก (`features/home/content/care.ts`) แก้ที่เดียวเปลี่ยนทั้งสองหน้า |
| ห้องและเครื่องมือในคลินิก | ไฟล์ content |
| สาขาและเวลาทำการ | API `GET /clinic/branches` และ `GET /clinic/hours` |
| ข้อมูลสถานพยาบาล | `frontend/src/config/site-footer.ts` (`footerLegal`) ชุดเดียวกับ footer |
| ปุ่มจองนัดและดูทีม | ไฟล์ content |

## สาขาและเวลาทำการ

ส่วนนี้อ่านจาก API ทุกครั้งที่เปิดหน้า จึงเปลี่ยนตามค่าที่คลินิกตั้งในระบบ ไม่ต้องแก้โค้ด

- เวลาทำการเรียงวันจันทร์ก่อน และไฮไลต์แถวของวันนี้ตามเวลาของคลินิก (กรุงเทพฯ)
- วันที่ปิดขึ้นว่า "ปิดทำการ" เป็นสีแดง
- วันหยุดพิเศษที่ยังมาไม่ถึงขึ้นเป็นรายการใต้ตาราง พร้อมบอกว่าปิดทุกสาขาหรือสาขาไหน ถ้าไม่มีวันหยุดส่วนนี้ไม่แสดง
- ถ้าคลินิกยังไม่ได้ตั้งเวลาทำการ (`configured: false`) หน้าจะบอกให้โทรสอบถามแทนตาราง
- ถ้าเรียก API ไม่ได้ ส่วนนี้ขึ้นข้อความแทน ส่วนอื่นของหน้ายังแสดงตามปกติ

## แก้ข้อความและรูป

- ข้อความทั้งหมดอยู่ที่ `frontend/src/features/about/content/about-page.ts`
- รูปอยู่ที่ `frontend/public/images/about/` เปลี่ยนรูปได้ด้วยการวางไฟล์ใหม่แล้วแก้ `src` ในไฟล์ content รูปปัจจุบันมาจาก Unsplash ใช้ได้ฟรีโดยไม่ต้องให้เครดิต แหล่งที่มาเขียนไว้ในหัวไฟล์ content
- ถ้าลบ `src` ออก หน้าจะแสดงกรอบว่างแทนรูป เลย์เอาต์ไม่เลื่อน

## ข้อจำกัด

- **เวลาทำการ** หน้านี้ footer การ์ดสถานที่บนหน้าแรก และหน้าติดต่อเรา อ่านจาก `GET /clinic/hours` ทั้งหมดแล้ว จึงแสดงชุดเดียวกันเสมอ ดู [ข้อมูลติดต่อ](contact.md)
- **ที่อยู่สาขา** มาจาก API ถ้าสาขายังไม่มีที่อยู่ การ์ดจะชี้ไปที่แผนที่บนหน้าแรก
