# บทความ

บทความสุขภาพสัตว์ที่ทีมสัตวแพทย์เขียนให้เจ้าของสัตว์อ่าน แสดงสามเรื่องล่าสุดบนหน้าแรก มีหน้ารวมบทความทั้งหมด และหน้าอ่านแต่ละเรื่อง ทุกคนอ่านได้โดยไม่ต้องเข้าสู่ระบบ

ฟีเจอร์นี้ไม่อยู่ใน contract เป็นส่วนขยายที่เจ้าของงานขอเพิ่ม เหตุผลและสิ่งที่ตั้งใจไม่ทำอยู่ใน [ส่วนขยายของสัญญา § 9](../contract-extensions.md)

## ใครใช้ ใช้ทำอะไร

| ใคร | ทำอะไรได้ |
|---|---|
| ทุกคน | อ่านรายการบทความและบทความแต่ละเรื่อง |
| ผู้ดูแลเซิร์ฟเวอร์ | ใส่บทความตัวอย่างด้วยคำสั่ง `seed-articles` |
| พนักงาน | ยังไม่มีทางเขียนหรือแก้บทความผ่านหน้าจอหรือ API |

## ข้อมูลของบทความ

| ช่อง | กติกา |
|---|---|
| `slug` | ที่อยู่ของบทความ เช่น `/articles/cat-vaccine-schedule` ใช้ได้แค่ตัวพิมพ์เล็ก ตัวเลข และขีดคั่นคำ ยาวไม่เกิน 80 ตัวอักษร ห้ามซ้ำ |
| `title` | ชื่อเรื่อง ไม่เกิน 200 ตัวอักษร |
| `summary` | คำโปรยหนึ่งถึงสองประโยค ไม่เกิน 500 ตัวอักษร |
| `body` | เนื้อหาเป็นข้อความล้วน บรรทัดว่างหนึ่งบรรทัดคือขึ้นย่อหน้าใหม่ ไม่เกิน 20,000 ตัวอักษร |
| `author_name` | ชื่อผู้เขียนตามที่ผู้อ่านเห็น เช่น สพ.ญ. มินท์ เก็บเป็นชื่อ ไม่ผูกกับบัญชีพนักงาน เพราะบทความอยู่นานกว่าสัญญาจ้าง |
| `reading_minutes` | เวลาอ่านโดยประมาณ 1 ถึง 120 นาที |
| `cover_image_path` | รูปปก เป็น path ใต้ `/public` ของหน้าเว็บ ขึ้นต้นด้วย `/` ไม่รับ URL ภายนอก ไม่ใส่ก็ได้ |
| `published_at` | เวลาเผยแพร่ ถ้าเป็นเวลาในอนาคต บทความยังไม่แสดง |

ค่าที่ผิดกติกาถูก entity ปฏิเสธด้วย `invalid_article` ตั้งแต่ตอนสร้าง

## Endpoint

| Method | Endpoint | ทำอะไร |
|---|---|---|
| GET | `/articles?limit=` | บทความที่เผยแพร่แล้ว เรียงใหม่สุดก่อน ไม่มีเนื้อหาเต็ม `limit` 1 ถึง 50 ไม่ส่งได้ 10 นอกช่วงตอบ `422 validation_failed` |
| GET | `/articles/{slug}` | บทความหนึ่งเรื่องพร้อมเนื้อหา |

- บทความที่ยังไม่ถึงเวลาเผยแพร่ ไม่อยู่ในรายการ และเปิดตรง ๆ ได้ `404` เหมือนบทความที่ไม่มีอยู่ คนนอกจึงรู้ไม่ได้ว่ามีเรื่องอะไรรอเผยแพร่
- รายการใช้ `limit` ไม่ใช้ cursor เพราะบทความมีไม่มาก ถ้าวันหนึ่งเยอะขึ้น เพิ่ม cursor ได้โดยไม่ทำให้ผู้ใช้เดิมพัง
- บทความสองเรื่องที่เผยแพร่เวลาเดียวกัน เรียงด้วย id ซึ่งเรียงตามเวลาที่สร้างอยู่แล้ว

## ใส่บทความตัวอย่าง

```sh
dotnet run --project backend/src/HappyPaws.Api -- seed-articles
# หรือใน Docker
docker compose run --rm api seed-articles
```

คำสั่งนี้ใส่บทความสี่เรื่องจาก `SampleArticles.cs` วันที่เผยแพร่ย้อนหลังจากวันที่รัน 2, 9, 16 และ 23 วัน รายการจึงมีลำดับ

- รันซ้ำได้ เรื่องที่มี slug อยู่แล้วถูกข้าม ไม่ถูกเขียนทับ คำสั่งบอกว่าใส่เรื่องไหน และข้ามเรื่องไหน
- ถ้าคลินิกแก้บทความในฐานข้อมูลไปแล้ว การรัน seed อีกครั้งไม่ทำให้สิ่งที่แก้หายไป
- ต้องรัน `migrate` ก่อน เพราะตาราง `articles` มาจาก migration `Articles`

**แก้หรือเพิ่มบทความตอนนี้ทำอย่างไร** ยังไม่มีหน้าจอหรือ API เขียนบทความ ทางที่มีคือแก้หรือเพิ่มเรื่องใน `SampleArticles.cs` แล้วรัน `seed-articles` (มีผลเฉพาะ slug ใหม่) หรือแก้แถวในตาราง `articles` โดยตรง

## หน้าเว็บ

| หน้า | ที่อยู่ | แสดงอะไร |
|---|---|---|
| หน้าแรก | `/` คอลัมน์ "บทความจากทีมสัตวแพทย์" | สามเรื่องล่าสุด จำนวนตั้งที่ `homeArticleCount` ใน `features/home/content/articles.ts` |
| รวมบทความ | `/articles` | ทุกเรื่อง สูงสุด 50 เรื่อง เมนู "บทความ" บน header และลิงก์ "บทความสุขภาพสัตว์" ใน footer พามาที่นี่ |
| อ่านบทความ | `/articles/{slug}` | ชื่อเรื่อง คำโปรย ผู้เขียน เวลาอ่าน วันที่เผยแพร่ รูปปก และเนื้อหา ชื่อแท็บของเบราว์เซอร์เป็นชื่อบทความ |

- หน้าเว็บเรียก API จากฝั่งเซิร์ฟเวอร์ทุกครั้งที่เปิดหน้า บทความใหม่จึงขึ้นทันทีโดยไม่ต้อง build ใหม่
- ถ้าเรียก API ไม่ได้ หน้าแรกยังเปิดได้ คอลัมน์บทความขึ้นข้อความว่ายังโหลดบทความไม่ได้ แทนที่ทั้งหน้าจะพัง ถ้าไม่มีบทความเลย ขึ้นว่ายังไม่มีบทความ
- เนื้อหาแสดงเป็นข้อความ แยกย่อหน้าที่บรรทัดว่าง ไม่แปลงเป็น HTML บทความจึงพา script หรือลิงก์เข้าหน้าเว็บไม่ได้
- รูปปกที่ยังไม่มี แสดงเป็นกรอบเส้นประ (`ImageSlot`) ใส่รูปจริงโดยวางไฟล์ใต้ `frontend/public/` แล้วตั้ง `cover_image_path` ของบทความ
- บทความที่ไม่มีอยู่แสดงหน้า 404 ของเว็บ

## ข้อจำกัดที่รู้อยู่

- ยังไม่มีการเขียน แก้ ซ่อน หรือลบบทความผ่าน API หรือหน้าจอ เพราะต้องตัดสินเรื่อง scope ก่อน ดู [ส่วนขยายของสัญญา § 9](../contract-extensions.md)
- ยังไม่มีหมวดหมู่ แท็ก หรือการค้นหาบทความ
- การเปิดอ่านบทความไม่ถูกนับสถิติ
- บทความตัวอย่างเป็นคำแนะนำทั่วไป ควรให้สัตวแพทย์ของคลินิกอ่านทวนก่อนเปิดใช้งานจริง
