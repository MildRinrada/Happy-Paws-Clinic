# ข้อมูลติดต่อและหน้าติดต่อเรา

เบอร์โทร สายด่วน อีเมล LINE Facebook Instagram เว็บไซต์ และแผนที่ของคลินิก เก็บในฐานข้อมูลเป็นรายการ พนักงานเพิ่ม แก้ และลบได้จากหน้าจอพนักงาน แล้วทุกหน้าที่แสดงข้อมูลติดต่อบนเว็บสาธารณะอ่านจากรายการเดียวกันนี้

ส่วนนี้เป็นส่วนขยายนอก contract ดู [contract-extensions.md § 15](../contract-extensions.md)

## ใครใช้

| ใคร | ทำอะไร |
|---|---|
| ผู้เยี่ยมชมเว็บ | ดูหน้า `/contact` footer และการ์ดที่ตั้งบนหน้าแรก ไม่ต้องเข้าสู่ระบบ |
| พนักงานที่ถือ `settings:write` | เพิ่ม แก้ ลบ และเรียงลำดับรายการที่หน้า **ข้อมูลติดต่อ** (`/settings/contacts`) |
| ผู้ดูแลเซิร์ฟเวอร์ | ใส่รายการตัวอย่างด้วยคำสั่ง `seed-contacts` |

## รายการหนึ่งมีอะไร

| ช่อง | ความหมาย |
|---|---|
| `kind` | ประเภท `phone` `emergency` `email` `line` `facebook` `instagram` `website` `map` `other` แต่ละประเภทแสดงต่างกัน |
| `label` | ข้อความเหนือข้อมูล เช่น โทรศัพท์คลินิก ยาวไม่เกิน 100 ตัวอักษร |
| `value` | ข้อมูลที่แสดง เช่น 02-123-4567 หรือที่อยู่ใต้แผนที่ ยาวไม่เกิน 500 ตัวอักษร |
| `url` | ลิงก์เมื่อกด (ไม่บังคับ) ต้องขึ้นต้นด้วย `http://` หรือ `https://` |
| `embed_url` | ลิงก์ฝังแผนที่ ใช้ได้กับ `map` เท่านั้น และต้องขึ้นต้นด้วย `https://www.google.com/maps/embed` |
| `branch_id` | สาขาที่รายการนี้เป็นของ ไม่ใส่คือทั้งคลินิก |
| `sort_order` | ลำดับการแสดง เลขน้อยขึ้นก่อน |

- **โทรศัพท์และสายด่วน** กดแล้วโทรออก ลิงก์ `tel:` สร้างจากตัวเลขใน `value` ไม่ต้องใส่ `url`
- **อีเมล** กดแล้วเปิดโปรแกรมอีเมล (`mailto:`)
- **LINE Facebook Instagram เว็บไซต์ และอื่น ๆ** กดแล้วเปิด `url` ถ้าไม่ใส่ `url` จะแสดงข้อมูลอย่างเดียว
- **แผนที่** ถ้ามี `embed_url` แสดงแผนที่สด ถ้าไม่มีแสดงที่อยู่พร้อมลิงก์ไป Google Maps
- รับเฉพาะลิงก์ `http` และ `https` เพื่อกันลิงก์ `javascript:` หรือ `data:` บนหน้าเว็บสาธารณะ

## API

| Method | Endpoint | Scope |
|---|---|---|
| GET | `/clinic/contacts` | สาธารณะ |
| POST | `/clinic/contacts` | `settings:write` |
| PATCH | `/clinic/contacts/{id}` | `settings:write` ช่องที่ไม่ส่งคงเดิม สตริงว่างล้าง `url` `embed_url` `branch_id` รองรับ `If-Match` |
| DELETE | `/clinic/contacts/{id}` | `settings:write` รองรับ `If-Match` |

ข้อมูลผิดรูปแบบได้ `422` ที่ช่องนั้นพร้อมข้อความภาษาไทย สาขาที่ไม่มีอยู่ได้ `422` ที่ `branch_id` version เก่าได้ `409` การเปลี่ยนรายการแผนที่ที่ยังมีลิงก์ฝังเป็นประเภทอื่นได้ `422` ที่ `embed_url` การแก้ไขไม่ถูกบันทึกลง audit log เหมือนข้อมูลคลินิกส่วนอื่น (โปรไฟล์ เวลาทำการ)

## หน้าเว็บสาธารณะ

**หน้า `/contact`** เมนู **ติดต่อ** ที่ header และลิงก์ "ช่องทางติดต่อทั้งหมด" ใน footer และบนหน้าแรกพามาที่นี่

- สายด่วนฉุกเฉินรายการแรกเป็นแถบสีแดงพร้อมปุ่มโทรอยู่บนสุด
- รายการอื่นเป็นการ์ด แบ่งกลุ่มเป็นทั้งคลินิก แล้วแยกตามสาขา หัวข้อกลุ่มขึ้นเมื่อมีรายการของสาขา แผนที่ของแต่ละกลุ่มอยู่ใต้การ์ดของกลุ่มนั้น
- ด้านข้างเป็นเวลาทำการจาก `GET /clinic/hours` ไฮไลต์วันนี้ ตารางเดียวกับหน้าเกี่ยวกับคลินิก

**footer ทุกหน้า**

- แถบสีแดงใช้รายการ `emergency` แรก ถ้าไม่มีรายการนี้แถบไม่แสดง
- คอลัมน์แรกใช้รายการ `map` แรก (ที่อยู่ แผนที่สดหรือรูป และปุ่มเปิด Google Maps)
- คอลัมน์ติดต่อใช้โทรศัพท์ของทั้งคลินิก สายด่วน อีเมล และไอคอน LINE Facebook Instagram ของทั้งคลินิก
- คอลัมน์เวลาทำการอ่านจาก `GET /clinic/hours` วันที่เวลาเหมือนกันติดกันรวมเป็นแถวเดียว เช่น จันทร์ - อาทิตย์

**การ์ดที่ตั้งบนหน้าแรก** แสดงเวลาทำการ โทรศัพท์ LINE ที่อยู่ และแผนที่ จากข้อมูลชุดเดียวกัน ส่วนที่จอดรถยังเป็นข้อความใน `features/home/content/location.ts` เพราะไม่มีที่เก็บใน API

footer และหน้าแรกเลือกรายการของทั้งคลินิกก่อน ใช้ของสาขาเมื่อทั้งคลินิกไม่มีรายการประเภทนั้น ถ้าเรียก API ไม่ได้ ส่วนที่ไม่มีข้อมูลจะไม่แสดง หน้าที่เหลือยังแสดงตามปกติ

## หน้าจอพนักงาน

`/settings/contacts` แท็บ **ข้อมูลติดต่อ** ในเมนู **ตั้งค่า** เห็นเฉพาะบัญชีที่ถือ `settings:write`

- รายการเรียงตามลำดับ แต่ละแถวบอกประเภท ชื่อ ข้อมูล ลิงก์ สาขา และป้าย "มีแผนที่ฝัง"
- **แก้ไข** เปิดฟอร์มในแถวนั้น **ลบ** ถามยืนยันอีกครั้ง
- **เพิ่มช่องทางติดต่อ** เปิดฟอร์มเปล่า ลำดับตั้งต้นต่อจากรายการสุดท้าย
- คำอธิบายใต้ช่องข้อมูลเปลี่ยนตามประเภท ช่องลิงก์ฝังแผนที่ขึ้นเฉพาะประเภทแผนที่ และบอกวิธีคัดลอกลิงก์จาก Google Maps
- ปุ่ม **ดูหน้าติดต่อเรา** เปิดหน้าสาธารณะในแท็บใหม่ บันทึกแล้วหน้าสาธารณะเปลี่ยนตามทันที

## ใส่ข้อมูลตัวอย่าง

```bash
dotnet run --project backend/src/HappyPaws.Api -- seed-contacts
```

ใส่ 7 รายการ (โทรศัพท์ สายด่วน อีเมล LINE Facebook Instagram แผนที่) ชุดเดียวกับที่ footer เคยเขียนไว้ในโค้ด ทำงานเฉพาะเมื่อยังไม่มีรายการเลย ถ้าคลินิกเพิ่มรายการของตัวเองแล้วคำสั่งนี้ไม่ทำอะไร ลิงก์ Facebook และ Instagram ในตัวอย่างชี้หน้าแรกของเว็บนั้น ต้องแก้เป็นบัญชีจริงของคลินิก

## ข้อจำกัด

- **ที่จอดรถ** และข้อมูลสถานพยาบาล (ใบอนุญาต ผู้ควบคุมกิจการ) ยังเป็นข้อความในไฟล์ เพราะไม่ใช่ช่องทางติดต่อ
- **ลิงก์ฝังแผนที่** ต้องเป็นลิงก์ embed ของ Google Maps เท่านั้น ผู้ให้บริการแผนที่อื่นใช้ได้แค่เป็นลิงก์ (`url`)
- **ยังไม่มีการลากเพื่อเรียงลำดับ** เปลี่ยนลำดับด้วยการแก้เลขลำดับ
