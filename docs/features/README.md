# สารบัญฟีเจอร์

แต่ละฟีเจอร์มีเอกสารของตัวเอง บอกว่าใครใช้ ใช้ทำอะไร ทำงานอย่างไร มีกติกาและข้อจำกัดอะไร และโค้ดอยู่ที่ไหน

สิทธิ์ในเอกสารเหล่านี้เขียนเป็น scope เช่น `queue:call` ส่วน role ใดถือ scope อะไรดูที่ [สิทธิ์](../authorization.md)

## งานประจำวันของคลินิก

| ฟีเจอร์ | เนื้อหา |
|---|---|
| [ตารางเวร](schedules.md) | เวรเดี่ยวและเวรซ้ำ เวลาพัก วันลาที่เสนอหมอแทน ช่วงว่างจริง และกติกาจ่ายเคส |
| [การจองและนัดหมาย](booking-and-appointments.md) | หาช่วงเวลาว่าง จองชั่วคราวระหว่างกรอกฟอร์ม ยืนยัน เลื่อน ยกเลิก และเช็กอินเข้าคิว |
| [นัดขั้นสูง](advanced-booking.md) | ไม่มาตามนัด นโยบายยกเลิกและค่าปรับ ประเภทนัด ตรวจนัดชน นัดซ้ำเป็นคอร์ส คิวรอ และแผนการรักษา |
| [คิว](queue.md) | บัตรคิวจากการเช็กอินและ walk-in ความเร่งด่วน มอบหมายหมอและห้อง เรียก ข้าม ออกจากคิว และกระดานคิวบนเว็บ |
| [การตรวจและเวชระเบียน](consultations-and-records.md) | เปิดเคส vitals ผลตรวจ วินิจฉัย การรักษา ใบสั่งยา ปิดเคส การเซ็นเวชระเบียน และการแก้ไขภายหลัง |
| [งานรักษาต่อเนื่อง](clinical-records.md) | วัคซีน กราฟน้ำหนัก แล็บ ประวัติยาและการจ่ายยา เทมเพลตแผนรักษา อัปโหลดเอกสาร และเอกสาร PDF |
| [สต๊อกยาและเวชภัณฑ์](inventory.md) | รายการในคลัง ล็อตและวันหมดอายุ รับเข้า จ่ายออก โอนสาขา ปรับยอด แจ้งเตือน ใบสั่งซื้อ และการจ่ายยาที่ตัดสต๊อกและคิดค่ายา |
| [การเงิน](billing.md) | ใบแจ้งหนี้ รับเงินหลายช่องทาง ส่วนลด คืนเงิน ใบเสร็จ ยกเลิกบิล และหน้าเก็บเงินบนเว็บ |
| [แพ็กเกจ คูปอง และแต้มสะสม](crm.md) | ขายแพ็กเกจและตัดสิทธิ์อัตโนมัติ คูปองส่วนลด แต้มสะสมกับระดับสมาชิก และกลุ่มลูกค้าสำหรับส่งประกาศ LINE |
| [ภาพรวมและรายงาน](dashboard.md) | การ์ดวันนี้ สถิตินัด คิว ภาระงาน รายรับ บริการทำเงิน ลูกค้าใหม่และกลับมา ผลงานรายบุคคล วิธีนับแต่ละตัวเลข และการส่งออกเป็นไฟล์ CSV, Excel หรือ PDF |
| [เตือนอัตโนมัติ](automation.md) | กติกาเตือนวัคซีน นัด และแผนการรักษา ดูตัวอย่างผู้รับก่อนเปิดใช้ เปิดปิด แก้ และลบกติกา ข้อความที่จะส่ง และตัวตั้งเวลาเบื้องหลัง |
| [คาดการณ์จากข้อมูลของคลินิก](forecasts.md) | ยาจะหมดเมื่อไรและควรสั่งเท่าไร ความหนาแน่นรายชั่วโมงเทียบกับหมอที่ลงเวร นัดที่เสี่ยงไม่มา รายชื่อลูกค้าที่ควรกลับมาแล้ว และกติกาเตือน "คิดถึงน้อง" คิดด้วยสถิติธรรมดาบนเซิร์ฟเวอร์ของคลินิก |
| [ผู้ช่วย AI สำหรับพนักงาน](staff-ai.md) | สรุปประวัติสัตว์ก่อนตรวจพร้อมที่มา ร่างบันทึกการตรวจจากบันทึกย่อ ร่างคำแนะนำหลังรักษาและคำตอบลูกค้า ถามตัวเลขของคลินิกตามสิทธิ์ของผู้ถาม สรุปเช้าแต่ละสาขา โควตารายเดือน และการแทนข้อมูลส่วนบุคคลก่อนส่งให้โมเดล |

## ทะเบียนและการตั้งค่า

| ฟีเจอร์ | เนื้อหา |
|---|---|
| [ตั้งค่าคลินิก](clinic-setup.md) | ข้อมูลคลินิก สาขา เวลาทำการ วันหยุด และการตั้งค่าการจอง คิว และเวชระเบียน |
| [พนักงานและสิทธิ์](staff-and-roles.md) | รายชื่อพนักงาน คำเชิญ การปิดบัญชี role และชุด scope |
| [บัญชีของตัวเอง](account.md) | แก้โปรไฟล์ ตั้ง 2FA เองพร้อม recovery code และการพักหรือปิดบัญชี |
| [บริการ](services.md) | รายการบริการ หมวด ราคาตามช่วงเวลา และช่วงที่เปิดจองออนไลน์ |
| [ลูกค้าและสัตว์เลี้ยง](customers-and-pets.md) | ลูกค้า สัตว์เลี้ยง ผู้ดูแลร่วม การรวมรายชื่อซ้ำ การผูก LINE ที่เคาน์เตอร์ การแพ้ยา และการบันทึกว่าสัตว์เสียชีวิต |

## ลูกค้าและการติดต่อ

| ฟีเจอร์ | เนื้อหา |
|---|---|
| [การเข้าสู่ระบบของลูกค้า](customer-sign-in.md) | ขอรหัส OTP สมัครด้วยเบอร์ เข้าสู่ระบบด้วยรหัส OTP หรือรหัสผ่าน และลืมรหัสผ่าน |
| [portal ลูกค้า](portal.md) | หน้าแรก สัตว์เลี้ยงและการแก้ข้อมูลของเจ้าของ ประวัติที่คลินิกเปิดให้เห็น กล่องแจ้งเตือน อัปโหลดไฟล์ และแพ็กเกจ |
| [ความยินยอมและข้อมูลส่วนบุคคล](privacy-and-consent.md) | ความยินยอมรายวัตถุประสงค์และเลขฉบับประกาศที่ระบบใส่ให้ คำขอเรื่องข้อมูล และประตูกั้นก่อนส่งข้อความทุกครั้ง |
| [ประกาศความเป็นส่วนตัวของคลินิก](privacy-policy.md) | คลินิกเขียนประกาศเอง ร่างและฉบับที่เผยแพร่แล้วแก้ไม่ได้ template ที่มากับระบบ รูปแบบเนื้อหา การเผยแพร่โดยเจ้าของคลินิก หน้า `/privacy` และฉบับเก่า |
| [การแจ้งเตือน](notifications.md) | ข้อความที่ระบบส่ง การเลือกช่องทาง LINE SMS อีเมล ประวัติการส่ง เทมเพลต และการส่งจากพนักงาน |
| [LINE](line.md) | ตั้งค่า LINE Official Account การประกาศ webhook ปุ่มในแชต และการเลือกที่อยู่ LINE ของลูกค้าจากผู้ติดตามล่าสุด |
| [การเชื่อมต่อระบบ](integrations.md) | webhook ขาออกพร้อม outbox ลายเซ็น และการลองใหม่ API key ค่าตั้งผู้ให้บริการชำระเงินและแล็บ และลิงก์ปฏิทินของพนักงาน |
| [หน้าแรกสาธารณะ](home-page.md) | หน้าแรกของคลินิก กล่องเวลาว่างเร็วสุด header footer การแก้ข้อความ และการใส่รูปจริง |
| [หน้าบริการและราคา](services-page.md) | หน้า `/services` บริการ ราคา ระยะเวลา จากเมนูสาธารณะ ทุกหมวด และปุ่มจองบริการนี้ |
| [ผู้ช่วย AI บนหน้าเว็บ](assistant.md) | แชทตอบเรื่องเวลาทำการ บริการ ราคา และเวลาว่าง โมเดลสลับได้ระหว่าง Gemini กับโมเดล open source ที่รันเอง |
| [ข้อมูลติดต่อและหน้าติดต่อเรา](contact.md) | เบอร์โทร อีเมล แชท และแผนที่ที่พนักงานแก้ได้ หน้า `/contact` และ footer ที่อ่านข้อมูลชุดเดียวกัน |
| [หน้าเกี่ยวกับคลินิก](about-page.md) | เรื่องราว สิ่งที่ยึดถือ เครื่องมือ สาขาและเวลาทำการจาก API และข้อมูลสถานพยาบาล |
| [รีวิวจากลูกค้า](reviews.md) | รีวิวจริงจากลูกค้าที่มาใช้บริการ ผ่าน portal หรือลิงก์ที่ใช้ได้ครั้งเดียว พนักงานอ่านก่อนเผยแพร่ เหตุผลไม่เผยแพร่ที่กำหนดไว้ ค่าเฉลี่ยจากรีวิวที่เผยแพร่ ชื่อที่แสดง การนำออกเมื่อลูกค้าขอ และการชวนรีวิวอัตโนมัติ |
| [ชวนเพื่อน](referrals.md) | ลิงก์ชวนเพื่อนของลูกค้าแต่ละคน เพื่อนที่เป็นลูกค้าใหม่จองผ่านลิงก์ แต้มของทั้งสองฝั่งเมื่อบิลแรกชำระ เพดานต่อเดือน การเปิดปิด และสิ่งที่แต่ละฝั่งเห็น |
| [บทความ](articles.md) | บทความสุขภาพสัตว์ หน้ารวมพร้อมช่องค้นหาและหน้าอ่าน สามเรื่องล่าสุดบนหน้าแรก และคำสั่งใส่บทความตัวอย่าง |
| [หน้ากรณีฉุกเฉิน](emergency-page.md) | หน้า `/emergency` ปุ่มโทรฉุกเฉิน คลินิกเปิดอยู่ไหมตอนนี้แยกตามสาขา อาการที่ต้องรีบมา สิ่งที่ควรทำและไม่ควรทำระหว่างทาง และสิ่งที่สัตวแพทย์ต้องตรวจก่อนเปิดใช้ |
| [ตารางวัคซีนน้อง](vaccine-schedule.md) | เครื่องมือสาธารณะ ใส่วันเกิดของสุนัขหรือแมวแล้วได้ตารางวัคซีน ที่มาของตาราง การแก้ไฟล์ข้อมูล และสิ่งที่สัตวแพทย์ต้องตรวจก่อนเปิดใช้ |
| [ทีมของเรา](team.md) | หน้ารวมบุคลากรแยกตามแผนก ความต่างของแผนกกับ role โปรไฟล์สาธารณะ และคำสั่งใส่บุคลากรตัวอย่าง |
