# เดโม: Happy Paws Clinic ระบบบริหารคลินิกสัตวแพทย์

repo นี้มีแต่ไฟล์เว็บเดโมที่บิลด์แล้ว Vercel นำ `public/` ขึ้นเว็บตรงๆ โดยไม่ต้องบิลด์

- `public/` คือเว็บทั้งหมด (HTML, CSS, JS และรูป) ทำงานในเบราว์เซอร์ล้วนๆ ข้อมูลตัวอย่างเก็บใน `localStorage` ของผู้ใช้แต่ละคน ไม่มีเซิร์ฟเวอร์และไม่มีการส่ง SMS อีเมล หรือ LINE จริง
- `vercel.json` ตั้งโฟลเดอร์ที่เสิร์ฟ ส่งทุกหน้ากลับไปที่ `index.html` (เว็บแบบหน้าเดียว) และตั้ง header ของเว็บ

ไฟล์ทั้งหมดในนี้ถูกเขียนทับทุกครั้งที่อัปเดตเดโม อย่าแก้ไฟล์ที่นี่ ให้แก้ในโปรเจกต์หลัก แล้วรัน `npm run deploy:demo` ในโฟลเดอร์ `frontend`
