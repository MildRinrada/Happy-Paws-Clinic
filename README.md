# Happy Paws Clinic

ระบบจัดการคลินิกสัตวแพทย์ ครอบคลุมงานหนึ่งวันของคลินิก ตั้งแต่ลูกค้าจองคิว มาถึงคลินิก รอเรียก เข้าห้องตรวจ หมอบันทึกเวชระเบียน ไปจนถึงเก็บเงินและออกใบเสร็จ รวมถึงการตั้งค่าคลินิก พนักงาน บริการ ลูกค้า และสัตว์เลี้ยง

หนึ่งการติดตั้งคือหนึ่งคลินิก ระบบไม่มีรหัสองค์กรในข้อมูล ไม่มีหน้าสลับคลินิก และไม่มีผู้ดูแลแพลตฟอร์มที่เห็นทุกคลินิก คลินิกเดียวมีได้หลายสาขา

สัญญาของ API คือไฟล์ [`API Reference.dc.html`](API%20Reference.dc.html) มี 164 endpoint ตอนนี้ทำแล้ว 123 endpoint พร้อมเทสต์ และมี endpoint ที่เพิ่มนอกสัญญาอีก 21 เส้น ซึ่งแต่ละเส้นมีเหตุผลเขียนไว้ใน [ส่วนขยายของสัญญา](docs/contract-extensions.md)

## ส่วนประกอบ

| ส่วน | เทคโนโลยี | โฟลเดอร์ | พอร์ตปกติ |
|---|---|---|---|
| หน้าเว็บ | Next.js 15, React 19, TypeScript, Tailwind CSS 4 | `frontend/` | 3000 |
| API | ASP.NET Core 10, Entity Framework Core 10 | `backend/` | 5080 (path เริ่มด้วย `/v1`) |
| ฐานข้อมูล | PostgreSQL 17 | `docker-compose.yml` | 5432 |

เบราว์เซอร์คุยกับหน้าเว็บอย่างเดียว หน้าเว็บฝั่งเซิร์ฟเวอร์เป็นคนเรียก API และถือ token ไว้ในคุกกี้ที่ JavaScript อ่านไม่ได้

## สิ่งที่ใช้งานได้ตอนนี้

| ส่วน | สถานะ |
|---|---|
| API งานประจำวัน | การจอง คิว การตรวจ เวชระเบียน ใบแจ้งหนี้ การรับเงิน ใบเสร็จ ครบทั้งหมด |
| API ตั้งค่าและทะเบียน | ข้อมูลคลินิก สาขา เวลาทำการ พนักงาน role บริการ ลูกค้า สัตว์เลี้ยง ตารางเวร และบัญชีของตัวเอง (โปรไฟล์ 2FA สถานะบัญชี) ครบทั้งหมด |
| API งานรักษาต่อเนื่อง | วัคซีน กราฟน้ำหนัก แล็บ ประวัติยาและการจ่ายยา แผนการรักษา อัปโหลดเอกสาร เอกสาร PDF นัดขั้นสูง (ไม่มาตามนัด นโยบายยกเลิก ประเภทนัด นัดซ้ำ คิวรอ) |
| API ฝั่งลูกค้า | สมัครด้วยเบอร์และ OTP เข้าสู่ระบบ ลืมรหัสผ่าน และ portal ครบทั้งหมวด |
| หน้าเว็บ | หน้าแรกสาธารณะ บทความ ทีมของเรา เข้าสู่ระบบพนักงาน (รหัสผ่านและรหัสจากแอป authenticator) กระดานคิว หน้าเก็บเงิน |
| ยังไม่มี | ตัวส่ง SMS อีเมล และ LINE จริง (รหัส OTP และลิงก์ต่าง ๆ ไปอยู่ใน log ของ API) หน้าจอฝั่งลูกค้า หน้าจอตั้งค่า หน้าตรวจรักษา คลังยา |

ดูรายละเอียดทั้งหมดใน [สถานะของระบบ](docs/system-overview.md)

## วิธีรัน

**ใช้ครั้งแรก อ่าน [เริ่มต้นใช้งาน](docs/getting-started.md)** หน้านั้นพาทำทีละขั้น บอกว่าแต่ละขั้นควรเห็นอะไร และแก้อย่างไรเมื่อไม่ได้ผล

ต้องติดตั้ง Docker Desktop, .NET SDK 10 และ Node.js 22 ก่อน แล้วรันจากโฟลเดอร์นี้ตามลำดับ

| ขั้น | คำสั่ง | ทำครั้งเดียว |
|---|---|---|
| 1. คัดลอกไฟล์ตั้งค่า | `cp .env.example .env` และ `cp frontend/.env.example frontend/.env.local` | ใช่ |
| 2. เปิดฐานข้อมูล | `docker compose up -d postgres` | ไม่ |
| 3. สร้างตารางและเจ้าของคลินิก | `migrate` แล้ว `bootstrap` คำสั่งเต็มอยู่ในขั้นที่ 3 ของ [เริ่มต้นใช้งาน](docs/getting-started.md) | ใช่ |
| 4. เปิด API (Terminal ที่หนึ่ง) | `dotnet run --project backend/src/HappyPaws.Api` | ไม่ |
| 5. เปิดหน้าเว็บ (Terminal ที่สอง) | `cd frontend` แล้ว `npm install` และ `npm run dev` | ไม่ |

เสร็จแล้วเปิด http://localhost:3000 เป็นหน้าแรก และ http://localhost:3000/login สำหรับพนักงาน

## กติกาหลักของโปรเจกต์

- **API คือด่านความปลอดภัย** หน้าเว็บซ่อนปุ่มตามสิทธิ์ได้ แต่ทุกคำขอถูกตรวจสิทธิ์ใหม่ที่ API เสมอ
- **ไม่แก้สัญญาเอง** ไม่เปลี่ยนชื่อ path ไม่เปลี่ยน method ไม่แต่ง endpoint ใหม่ จุดที่กำกวมบันทึกใน [ข้อสมมติ](docs/assumptions.md)
- **ไม่มีไฟล์ยักษ์** use case หนึ่งเรื่องหนึ่งโฟลเดอร์ การเรียก API หนึ่งเรื่องหนึ่งไฟล์ type อยู่กับฟีเจอร์ของมัน
- **LINE ใช้ส่งข้อความเท่านั้น** ไม่ใช้เข้าสู่ระบบ และไม่ใช้ผูกบัญชี
